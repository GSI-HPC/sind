sind runs each Slurm node as a Docker container. The official images, one per supported Slurm release line, include Slurm with PMIx support and a full OpenMPI stack (UCX, PMIx, PRRTE, OpenMPI), all compiled from source. This section covers the official images and how to build custom images.
